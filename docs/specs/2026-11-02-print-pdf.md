# 2026-11-02 打印/存为 PDF 流程重做（横竖版选择 + 多页修复）— spec 契约

> 本文件是需求的唯一事实来源。用户确认 = 签约，之后编码/测试/验收/PR 全部从本文件派生。
> 需求来源：用户 2026-11-02 对 v1.1.1 打印提示改动的验收反馈（Step 5 未通过），原话三条：
> 1. "点击打印/存为PDF 并没有看到下载PDF的格式"
> 2. "打印的预览界面中可以看到除了第一页之外，其他页面都是异常的"
> 3. "点击按钮之后提示用户是下载横版还是竖版因为页面是支持三端的。所以需要做选择之后的模板进行打印或者下载PDF"
>
> **修订（2026-11-03，第二轮验收反馈）**：用户实机打印预览截图反馈两点——①「跟网的区别首先底色没有了」（v1.1.0 打印白底规则被否决）②「格式都显示的也不对」（横版第 2 页大块空白：CDP 实测 RMS 履历块高 771px，超过 A4 横版页高 718px，`break-inside: avoid` 把整块挤到下一页）。据此修订 C15：背景色改为**保留屏幕暖色底**（`print-color-adjust: exact` 保证输出）；分页规则改为 `.sec-head-wrap` 不可拆分、`.tl-item` **允许跨页**（子块 `.tl-proj` 不拦腰截断）。

## 1. 背景与目标（what & why）

v1.1.0 的打印功能只有一个 `window.print()` 直调 + 按钮 tooltip 提示，实测暴露三个问题：

- **PDF 下载路径不清晰**：按钮叫「打印 / 存为 PDF」，但点击后直接弹系统打印对话框，用户找不到「另存为 PDF」在哪里（反馈 1）；
- **多页打印异常**：GSAP 入场动画用 `gsap.from(..., { autoAlpha: 0 })` + ScrollTrigger，未滚动到的 section 在 DOM 上残留内联 `opacity:0; visibility:hidden; transform:translateY(...)`。打印预览渲染整份文档时，第 2 页起的内容（履历/技能/项目/页脚）处于隐藏或错位状态（反馈 2，已定位根因）；
- **无版式选择**：页面支持三端（1440/768/390 断点），打印时应让用户先选**横版/竖版**，按所选模板打印/下载 PDF（反馈 3）。

目标：点击「打印 / 存为 PDF」→ 弹出**版式选择对话框**（竖版/横版）→ 按所选方向注入 `@page` 与版式类 → 打开系统打印对话框，对话框内以显著文案指引「另存为 PDF」；同时修复多页打印（动画状态不泄漏进打印），使任意页打印预览完整正常。版本 v1.2.0。

> 技术约束（不变）：公司防火墙拦截 >35KB 上传，**零依赖**约束成立——jsPDF/html2canvas 无法引入，浏览器打印对话框的「另存为 PDF」是唯一 PDF 路径。本次做的是**流程引导 + 打印模板**，不是自造 PDF 引擎。

## 4. 契约条款（C13 / C14 / C15 / C16）

> 编号承接 `docs/specs/2026-10-31-tech-redesign.md`（C1-C12）的项目级序列。

### C13 打印/存为 PDF 版式选择对话框（横版/竖版）

- **前置条件**：任一版本页（`/ai /it /test /erp`）渲染完成
- **后置条件**：点击「打印 / 存为 PDF」按钮 → 弹出**居中对话框**（遮罩 + 卡片，暖色风格与页面一致），含：① 标题「选择打印版式」② 两个版式选项卡——**竖版**（A4 竖版 · 单列紧凑）与**横版**（A4 横版 · 双列宽版），各带方向示意图标 ③ 显著提示文案：选择后打开系统打印对话框，在「目标打印机」中选择「**另存为 PDF**」即可下载 PDF 文件 ④ 关闭方式：× 按钮 / Esc / 点遮罩；选择任一版式 → 关闭对话框并触发打印（C15 流程）；4 个版本行为一致；**中英双语**：英文页面下对话框文案为英文（Choose print layout / Portrait / Landscape / Save as PDF 提示）
- **失败行为**：对话框打开时再点打印按钮 = 无操作（幂等，不叠层）；Esc/关闭后不触发打印、无状态残留
- **不变式**：对话框为纯前端本地状态（无网络请求）；不依赖 GSAP（GSAP 加载失败时对话框仍可用）；按钮文案保持「打印 / 存为 PDF」/「Print / Save as PDF」

### C14 多页打印修复（动画状态不泄漏进打印）

- **前置条件**：页面加载后**未滚动**（下方 section 的 GSAP 入场动画未触发，DOM 残留内联 `opacity:0; visibility:hidden; transform:...`）
- **后置条件**：`@media print` 内以 `!important` 覆盖全部动画残留——`opacity: 1 !important; visibility: visible !important; transform: none !important`（作用于 `*`），使打印预览中**每一页**（第 2 页起的履历/技能/项目/页脚）内容完整可见、无位移错位；屏幕端动画不受影响（覆盖仅在 print 媒体内生效，打印结束后页面动画继续）
- **失败行为**：GSAP 加载失败时本条天然满足（无内联残留）
- **不变式**：不修改/不杀死屏幕端 GSAP 动画状态（不用 JS 清 inline style，纯 CSS 覆盖）；`prefers-reduced-motion` 行为不变

### C15 打印版式模板（@page A4 + 横竖版布局 + 分页规则）

- **前置条件**：用户在对话框选择竖版或横版（或直接 Ctrl+P）
- **后置条件**：
  - **@page**：静态默认 `@page { size: A4 portrait; margin: 16mm }`（style.css，兜底 Ctrl+P）；对话框选择时注入动态 `<style>` `@page { size: A4 ' + o + '; margin: 16mm }`（打印结束 afterprint 后清理）。margin 16mm 给纸边留白；奶油色内容区内缩方案：body 背景改白底（`background: #fff !important`），奶油色移到 `#app`（内层 div，非传播元素）+ `margin: 0 6mm`——因 body 背景会传播到 canvas 填满 @page 无法用 margin 内缩，改用 #app 才能真正内缩背景；纸边到奶油色 = 16mm + 6mm = 22mm 白色过渡带（2026-11-04 第六轮反馈「白色主题内容边缘太贴近边缘」）；竖版 body 178mm / 横版 265mm
  - **版式类**：`html.print-portrait` → 单列紧凑（hero 单列人像居上、stats 2 列、技能 2 列、项目单列、教育/荣誉单列、页脚单列）；`html.print-landscape` → 双列宽版（hero 左文右图、stats 4 列、技能 4 列、项目 2 列、教育/荣誉 2 列、页脚 2 列）；版式类规则全部在 `@media print` 内，屏幕端零影响
  - **打印宽度重置**（2026-11-03 第四轮反馈「左右都裁切」根因修复）：屏幕端 section 子元素 `max-width: 1200px` + `margin: auto` 居中、body 满视口宽——打印时若不重置，元素按屏幕视口（1440px）排版，宽度达 1200-1424px 远超 A4 竖版内容区 718px / 横版 1047px，打印引擎把超宽内容塞进 @page 必然左右裁切。打印块内须将 body 及所有 section/容器 `max-width: none; width: 100%`，使元素填满 @page 内容区而非屏幕视口；`clamp()` 字号中的 `vw` 单位在打印下基于屏幕视口，需在打印块内以固定 px 覆盖（hero-name/sec-head/footer-sentence）
  - **分页规则**：封面 `.hero` 不跨页（`break-inside: avoid`）且**独占第 1 页**（`.history` 从新页开始，`break-before: page`）；section 标题块 `.sec-head-wrap`（标题+副题）不跨页拆分（`break-inside: avoid` + `break-after: avoid`，标题永不脱离内容）；小卡片（`.stat .eh-card .skill-badge .tl-proj .proj .pf-text .pf-side`）`break-inside: avoid`；`.tl-item`（单段履历块）**允许跨页**——CDP 实测 RMS 履历块高 771px 超过 A4 横版页高 718px，强制不拆会把整块挤到下一页造成大面积空白页，跨页拆分（在 `.tl-proj` 子块边界断）优于空白页；后续 section（`.skills .projects .footer`）**不强制新页**（连续流动）——CDP 分页模拟证实对每个 section 都强制 `break-before: page` 会在 section 尾部产生近空白页（横版第 4 页 3%、第 6 页 15%），故仅 `.history` 强制新页以保证封面独占；文本 `orphans/widows: 3`
  - **背景色**：打印保留屏幕暖色底（body `#faf5ec` / 技能带 `#f1e7d3` / 卡片 `#fffdf8` / 深色页脚 `#3d3529`），与网页观感一致（2026-11-03 用户验收反馈：白底规则废除）；`* { -webkit-print-color-adjust: exact; print-color-adjust: exact; }` 保证打印对话框未勾选「背景图形」时背景仍输出；仍隐藏顶栏/打印按钮/模糊背景/hover 提示
  - **色带内边距**（2026-11-03 第三轮反馈「竖版边线裁切」修复）：带背景色的 section（`.skills` 奶油底 / `.footer` 深色底）在打印时保留左右内边距，使色带在卡片外侧留出可见宽度——CDP 像素扫描证实竖版 2 列布局下 `.skill-grid` 卡片几乎占满 718px 可打印宽度，奶油色带仅剩左右各 1px（打印易丢失/似被裁切）；横版 4 列卡片更窄、间隙更多故不明显。打印块内 `.skills { padding: 40px 32px; }`（左右 32px 让色带可见），`.footer` 已有 `padding` 内边距无需额外处理；非色带 section（`.history .projects` 无背景色）保持 `padding: 40px 0`
- **失败行为**：动态 `<style>` 注入失败（极端）→ 回退静态 `@page` portrait，打印仍可用
- **不变式**：A4 纸；打印不出现红色系；背景必须输出（`print-color-adjust: exact`）；`@page` 规则只影响打印，不影响屏幕
