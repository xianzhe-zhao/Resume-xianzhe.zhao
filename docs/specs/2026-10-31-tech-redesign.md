## 1. 背景与目标（what & why）

v1.0.0 已完成多版本简历系统（AI/IT/测试/ERP 四版本 + 密码管理后台 + 头像上传 + 导出 HTML）。上次会话按 taste skill 重做了画风，但产出的方向与用户诉求错位：

- 配色为 Oxblood 深红（`#7d0c14`）——用户明确"红色不好看"，要求**科技感**；
- 图片为雾景/树林/湖面/海岛 + "书脊"项目索引——用户明确"跟 AI 或开发者没有任何关系"，要求**富有科技感的照片**；
- 首屏是 14rem 巨字姓名，职位与差异化信息缩在角落——**重点不突出**，未针对 AI/开发者岗位组织内容；
- `/admin` 因重写 style.css 时删掉了全部后台样式而**碎片化**（实测：登录页文字贴边 0px、87% 空白、控件无样式）；
- 附带布局缺陷：showcase 区 "1400h" 与 "9yr" 两个巨字并排粘连成 "1400h9"。

目标：按 design-taste-frontend（页面重设计 + app-screens 后台）+ gsap-core 重新设计，产出**暖色风格**、**五段式结构**（封面卡通人像/个人履历/作品目录悬浮技能/项目展示/页脚）、**中英双语**（默认中文，按钮切英文）、AI/开发者重点突出、后台完整可用的 v1.1.0。

> 签约补充（用户 2026-10-31 确认）：配色走**浅色**科技感（非深色）；图片要求**有科技感但简约、观感干净**，不要复杂场景。

## 6. 边界与异常

| 场景 | 期望表现 |
|---|---|
| resume.json 某字段为空字符串 | 对应区块隐藏或留空，不破版、不渲染 "undefined" |
| 图片文件缺失（404） | 图片容器保留高度（纯色块），页面不破版 |
| GSAP/ScrollTrigger 加载失败 | 全部内容可见，无动画，无 JS 报错中断渲染 |
| /admin 未登录访问 | 只显示登录页；/api/save 返回 401 |
| /api/login 错误密码 | 401 + "密码错误"，不泄露更多信息 |
| /api/upload 图片 >2MB | 400 + "图片过大（限 2MB）" |
| /api/save 非 JSON 请求体 | 400 + "数据格式错误"，不泄露堆栈 |
| 390px 视口 | 无水平溢出，首屏完整（见 C11） |
