## 1. 背景与目标（what & why）

v1.9.0（origin/test 基线 c3d5c06）的打印/存为 PDF 功能实测暴露三个问题（用户 2026-11-25 反馈）：hero 区打印按钮点击无反应；打印预览中封面图片未加载完成（空白封面）；打印内容贴边、分页滞留标题/近空白页/封面截断。修订 1–3 逐步修复（C17–C21），其中修订 3 的分页机制（动态 @page 26mm 16mm + 强制分页规则）于 2026-11-26 验收不合格：用户反馈 4「你看内容都是割裂的。我不想要这样的效果有没有什么解决办法 你去网上搜。针对页面打印出来PDF导致的内容撕裂的解决办法」——内容被 A4 分页线拦腰截断（割裂）不可接受。

**修订 4 目标**：① WYSIWYG 打印预览——选竖/横版后在屏幕上渲染导出 PDF 的版式（连续长纸张，无分页线）；② 不分页长页导出——PDF 恰好 1 页（210/297mm 宽 × 内容总高 + 20mm 缓冲），无分页、无截断、无留白（用户三选一中选定「完全不分页」）；③ 预览与导出同源（所见即所得）；④ 直接 Ctrl+P 同样输出长页，杜绝旧机制撕裂输出残留。C17（双按钮）/C18（图片完整）承接不变。版本 v1.9.1（bug 修复，SemVer patch）。

### C19 WYSIWYG 打印预览（长页版）

### C20 不分页长页导出（恰好 1 页）

- **前置条件**：用户在预览点「导出 PDF」（或直接 Ctrl+P，见 C23）
- **后置条件**：动态 `@page { size: 210mm × H（竖版）/ 297mm × H（横版）; margin: 0 }` 已注入（H 按 C21）；导出 PDF（系统打印对话框「另存为 PDF」/ CDP `Page.printToPDF` preferCSSPageSize + printBackground）**恰好 1 页**；内容自首屏（hero）到页脚（footer）完整连续，无分页、无截断、无大面积空白；页面底部白边 = 26mm 白边 + 残余缓冲（≤20mm），顶部/左右白边与预览一致（上下 26mm、左右 30mm 到内容）

### C21 总高测量（稳定轮询 + 20mm 缓冲）

- **失败行为**：4 秒超时未稳定 → 以最后一次读数定稿（20mm 缓冲覆盖残余漂移）
- **不变式**：实测依据（2026-11-26 原型 CDP）：打印引擎排版比屏幕高约 10mm（行高舍入），20mm 缓冲 = 2 倍余量；屏幕与打印模拟布局逐项一致（#app 竖版 12172px / 横版 9221px）
